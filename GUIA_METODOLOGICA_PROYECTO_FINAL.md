## 3. REGLAS DE NEGOCIO ESTRICTAS DE "OKI DOKI"

1. **Giro Comercial Mayorista:** Distribuidora mayorista de consumo masivo y abarrotes en Bolivia (aceite, fideo, arroz, azúcar, leche, bebidas y limpieza), comercializados exclusivamente en unidades mayoristas (cajas, fardos, paquetes y quintales de 50 kg) identificados por código SKU único.
2. **Moneda Oficial:** **Bolivianos (`Bs.`)**. Todo subtotal, precio unitario y total facturado se expresa obligatoriamente en `Bs.`.
3. **PROHIBICIÓN ESTRICTA (Cero Transportistas):**
   * Oki Doki opera bajo la modalidad de **retiro directo en almacén central / mostrador**.
   * **Queda terminantemente prohibido** incluir entidades, campos o endpoints de choferes, vehículos, transportistas, comisiones de entrega o rutas logísticas.
4. **Transacciones Atómicas (ACID):**
   * El checkout valida disponibilidad en tiempo real (`stock_actual >= cantidad_solicitada`).
   * Si cualquier ítem no tiene existencias suficientes, se aborta la operación completa mediante `db.rollback()` devolviendo `HTTP 400 Bad Request`.
   * Toda salida genera automáticamente un registro inmutable en el Kardex (`inventory_movements`).

## 4. FASE 1: BASE DE DATOS Y BACKEND (SUPABASE + FASTAPI EN RENDER)

### Paso 1.1: Base de Datos en Supabase (PostgreSQL)
1. Iniciar sesión en [Supabase](https://supabase.com/) y crear un proyecto gratuito.
2. Ingresar al **SQL Editor** y ejecutar el script DDL con las tablas base:

```sql
-- TABLA DE PRODUCTOS MAYORISTAS
create table if not exists products (
    id bigint generated by default as identity primary key,
    sku text unique not null,
    name text not null,
    price numeric(12, 2) not null check (price > 0),
    cost_price numeric(12, 2) default 0.0,
    stock integer default 0 not null check (stock >= 0),
    min_stock integer default 10 not null,
    image_url text,
    created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- TABLA DE CLIENTES DE MOSTRADOR
create table if not exists customers (
    id bigint generated by default as identity primary key,
    nombre_razon_social text not null,
    nit_ci text not null,
    telefono text,
    tipo_cliente text default 'Mayorista Mostrador' not null,
    activo boolean default true not null
);

-- TABLA DE CABECERA DE VENTAS
create table if not exists sales (
    id bigint generated by default as identity primary key,
    voucher_code text unique,
    total_amount numeric(12, 2) not null,
    created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- TABLA DE DETALLE DE VENTAS
create table if not exists sale_items (
    id bigint generated by default as identity primary key,
    sale_id bigint references sales(id) on delete cascade not null,
    product_id bigint references products(id) not null,
    quantity integer not null check (quantity > 0),
    unit_price numeric(12, 2) not null
);

-- TABLA DE KARDEX / AUDITORÍA INMUTABLE
create table if not exists inventory_movements (
    id bigint generated by default as identity primary key,
    product_id bigint references products(id) not null,
    movement_type text not null check (movement_type in ('ENTRADA', 'SALIDA', 'AJUSTE')),
    quantity integer not null,
    previous_quantity integer not null,
    final_quantity integer not null,
    document_reference text not null,
    movement_date timestamp with time zone default timezone('utc'::text, now()) not null
);

-- HABILITAR ROW LEVEL SECURITY (RLS)
alter table products enable row level security;
create policy "Lectura pública de catálogo" on products for select to public using (true);
create policy "Inserción autorizada" on products for insert with check (true);
```

#### C. `database.py` (Con Fallback Resiliente)
```python
import os
from sqlalchemy import create_engine
from sqlalchemy.orm import declarative_base, sessionmaker
from dotenv import load_dotenv

load_dotenv()

DATABASE_URL = os.getenv("DATABASE_URL", "sqlite:///./sql_app.db")

# Normalizar controlador para SQLAlchemy 2.0 (psycopg2)
if DATABASE_URL.startswith("postgresql://"):
    DATABASE_URL = DATABASE_URL.replace("postgresql://", "postgresql+psycopg2://", 1)

try:
    if DATABASE_URL.startswith("sqlite"):
        engine = create_engine(DATABASE_URL, connect_args={"check_same_thread": False})
    else:
        # Prueba de conexión con timeout corto para no bloquear el inicio
        engine = create_engine(DATABASE_URL, pool_pre_ping=True, connect_args={"connect_timeout": 3})
        with engine.connect() as conn:
            pass
except Exception as e:
    print(f" [RESPALDO AUTOMATICO] Error conectando a Supabase ({e}). Usando SQLite local.")
    DATABASE_URL = "sqlite:///./sql_app.db"
    engine = create_engine(DATABASE_URL, connect_args={"check_same_thread": False})

SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)
Base = declarative_base()

def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
```

#### D. `main.py` (Extracto Clave: Webhook Slack & Checkout ACID)
```python
import os, urllib.request, json
from fastapi import FastAPI, Depends, HTTPException, status, Header
from sqlalchemy.orm import Session
import models, schemas
from database import engine, get_db

models.Base.metadata.create_all(bind=engine)
app = FastAPI(title="ERP Oki Doki API")

def notificar_slack(mensaje: str) -> bool:
    """Envía alertas a Slack mediante Webhook oficial."""
    url = os.getenv("SLACK_WEBHOOK_URL", "").strip()
    if not url or "hooks.slack.com" not in url:
        return False
    try:
        payload = json.dumps({"text": mensaje}).encode("utf-8")
        req = urllib.request.Request(url, data=payload, headers={"Content-Type": "application/json"})
        with urllib.request.urlopen(req, timeout=3) as resp:
            return resp.status == 200
    except Exception:
        return False

@app.post("/api/v1/sales/checkout", status_code=status.HTTP_201_CREATED)
def checkout_sale(sale_in: schemas.SaleCreate, db: Session = Depends(get_db)):
    total = 0.0
    try:
        for item in sale_in.items:
            prod = db.query(models.Product).filter(models.Product.id == item.product_id).first()
            if not prod or prod.stock < item.quantity:
                raise HTTPException(status_code=400, detail="Stock insuficiente en almacén")
            
            # Descuento en tiempo real
            prod.stock -= item.quantity
            total += prod.price * item.quantity

        db_sale = models.Sale(total_amount=round(total, 2))
        db.add(db_sale)
        db.commit()
        db.refresh(db_sale)

        # Disparar alerta a Slack (Herramienta 2)
        notificar_slack(f"⚡ *Venta Mayorista Registrada*: Total cobrado: *Bs. {db_sale.total_amount:.2f}*")
        return db_sale
    except HTTPException:
        db.rollback()
        raise
```

### Paso 2.2: Incorporación del Gráfico 3D (Herramienta 5: Three.js)
El visor 3D permite que el cliente o encargado de almacén inspeccione visualmente el tipo de empaque (caja de 12 unidades, fardo de fideos o saco quintal de 50 kg) en 360° con controles orbitales de ratón:

```javascript
// Inicialización del visor 3D con Three.js y OrbitControls
function initVisor3D() {
  const container = document.getElementById("canvas-container");
  const scene = new THREE.Scene();
  const camera = new THREE.PerspectiveCamera(45, container.clientWidth / container.clientHeight, 0.1, 100);
  camera.position.set(3.5, 2.5, 4.5);

  const renderer = new THREE.WebGLRenderer({ antialias: true, alpha: true });
  renderer.setSize(container.clientWidth, container.clientHeight);
  container.appendChild(renderer.domElement);

  // Iluminación de estudio
  scene.add(new THREE.AmbientLight(0xffffff, 0.7));
  const dirLight = new THREE.DirectionalLight(0xffffff, 0.9);
  dirLight.position.set(5, 10, 7);
  scene.add(dirLight);

  // Empaque 3D Mayorista
  const geometry = new THREE.BoxGeometry(2.2, 1.8, 1.6);
  const material = new THREE.MeshStandardMaterial({ color: 0xb4793b, roughness: 0.5 });
  const boxMesh = new THREE.Mesh(geometry, material);
  scene.add(boxMesh);

  // Controles orbitales con el ratón
  const controls = new THREE.OrbitControls(camera, renderer.domElement);
  controls.enableDamping = true;

  function animate() {
    requestAnimationFrame(animate);
    boxMesh.rotation.y += 0.008;
    controls.update();
    renderer.render(scene, camera);
  }
  animate();
}
```
