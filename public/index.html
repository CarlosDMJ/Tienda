📋 Protocolo de Despacho en Almacén

  • Cero Transportistas: El cliente mayorista realiza el pago y retira la mercancía directamente en las puertas del almacén central.
  • Transacción ACID Garantizada: Si dos vendedores intentan despachar el último fardo simultáneamente, la base de datos de Supabase bloquea el sobregiro garantizando consistencia inmutable.
  • Comprobante Oficial: Se genera una numeración correlativa única (ej. VTA-20261022-0001).
  • Notificación en Tiempo Real: Cada venta confirmada dispara una alerta instantánea vía Webhook a Slack.
